# QA-Portafolio
Planes de prueba, diseño de casos y reporte de bugs sobre proyectos de práctica.

🎯Objetivo
Este repositorio documenta mi proceso de aprendizaje y práctica de QA: planes de prueba, diseño de casos de prueba, ejecución y reporte de bugs sobre sitios de práctica públicos.

🧰Habilidades demostradas en este repo:
Diseño de casos de prueba (partición de equivalencia, valores límite, casos negativos).
Documentación de planes de prueba.
Reporte de bugs con severidad, prioridad y evidencia (ver pestaña Issues de cada proyecto)
Pensamiento crítico orientado al usuario final.

📂 Proyectos
Proyecto 1: Testing de Login — SauceDemo
Testing manual del módulo de login de SauceDemo, incluyendo:

Plan de pruebas
10 casos de prueba (positivos, negativos y de borde)
Bugs reportados como Issues con evidencia
